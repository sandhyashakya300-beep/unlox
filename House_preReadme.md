# 🏠 House Price Prediction using Python

## 📌 Project Overview

This project focuses on analyzing and preparing the **Bengaluru House Prices** dataset using Python. It demonstrates a complete data analysis workflow including data cleaning, preprocessing, feature engineering, encoding categorical variables, and exploratory data analysis (EDA). The project helps understand the factors that influence house prices and prepares the dataset for machine learning models.

---

## 🚀 Features

* 📂 Load and explore the Bengaluru House Prices dataset
* 🧹 Handle missing values and duplicate records
* 🔄 Data preprocessing and cleaning
* 📊 Exploratory Data Analysis (EDA)
* 🏗️ Feature Engineering
* 🏷️ Label Encoding and One-Hot Encoding
* 📈 Data visualization using Matplotlib and Seaborn
* 📐 Convert and clean `total_sqft` values
* 🏡 Extract BHK information from house size
* 📉 Analyze price distribution and important features

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/your-username/House-Price-Prediction.git
```

Move into the project folder:

```bash
cd House-Price-Prediction
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the notebook:

```bash
jupyter notebook
```
