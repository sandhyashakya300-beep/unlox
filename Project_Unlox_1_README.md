# unloxPython Mini Projects Collection

A clean and beginner-friendly collection of Python console-based projects built using Python and NumPy. This repository contains simple programs that help beginners understand functions, loops, conditional statements, user input handling, and basic data analysis.

🚀 Projects Included
1. Smart Calculator

A console-based calculator that performs:

Addition
Subtraction
Multiplication
Division
Power
Modulus
Features
User-friendly menu
Handles multiple mathematical operations
Division-by-zero check
2. Student Marks Analyzer

A Python program that analyzes student marks and calculates:

Total marks
Highest marks
Lowest marks
Average marks
Grade evaluation
Features
Uses NumPy for calculations
Automatic grade assignment
Simple and interactive interface
3. Daily Expense Tracker

A simple expense tracking application that helps users:

Record daily expenses
Calculate total expenses
Find average expense
Identify highest and lowest expenses
Features
Expense statistics using NumPy
Interactive user input
Beginner-friendly implementation
