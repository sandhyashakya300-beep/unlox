# 📈 UNLOX Audience Intelligence Dashboard

A **Streamlit-powered Audience Intelligence Dashboard** that simulates content performance analytics using historical telemetry data and provides actionable recommendations for improving audience engagement.

This project demonstrates how **Python, Streamlit, Pandas, NumPy, and Plotly** can be combined to build an interactive analytics platform with real-time KPI visualization and recommendation capabilities.

---

## 🚀 Features

* 📊 Interactive dashboard built with Streamlit
* 📈 Real-time KPI metrics
* 📦 Simulated telemetry data generation
* 🎯 Rule-based recommendation engine
* 📉 Engagement and retention analytics
* 📊 Interactive Plotly visualizations
* ⚡ Cached data loading for improved performance
* 🧠 Data-driven content optimization insights

---

## 🛠️ Technologies Used

* Python 3.x
* Streamlit
* Pandas

* Plotly Express

## 📊 Dashboard Overview

The application includes:

### 📌 Audience Intelligence KPIs

* Aggregate Organic Yield
* Mean Save-to-Share Ratio
* Dominant Struggle Cluster

### 📌 Recommendation Engine

Provides recommendations such as:

* High-performing content topic
* Optimal video duration
* Caption architecture suggestions
* Data-driven content strategy

### 📌 Visualizations

#### Topic Cluster vs Organic Yield

Interactive box plot showing follower acquisition across different audience struggle topics.

#### Engagement Velocity vs Retention

Scatter plot illustrating the relationship between engagement and audience retention.

---

## 🧠 Recommendation Engine

The dashboard contains a rule-based analytics engine that recommends:

* Best-performing audience topic
* Recommended content duration
* Caption optimization strategy

These recommendations are generated using historical performance metrics.

---

## 📈 Dataset

This project uses a **simulated telemetry dataset** containing approximately **1,200 observations**.

Sample attributes include:

* Asset ID
* Struggle Topic Cluster
* Save-to-Share Ratio
* Cohort Retention Rate
* Organic Follower Yield
* Video Duration
* Linguistic Trigger Density

The dataset is generated dynamically using NumPy for demonstration purposes.

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/yourusername/unlox-audience-dashboard.git
```

Move into the project folder:

```bash
cd unlox-audience-dashboard
```

Install dependencies:

```bash
pip install -r requirements.txt
```

---

## ▶️ Run the Application

```bash
streamlit run app.py
```

The dashboard will open automatically in your browser.
